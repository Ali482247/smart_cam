# Приложение съёмки — что починить

Версия 1.1.0. Шесть пунктов, по убыванию важности. Подробности и примеры — в
`BUG_REPORT_shooting_app.md`, здесь только суть.

---

## 1. Номер устройства уезжает к другому телефону

**Что происходит.** Три телефона пишут файлы с `device_1/2/3` в имени. Иногда номер
достаётся не тому аппарату.

14.08 — телефоны 1 и 2 обменялись номерами на 123 записях подряд.
16.08 — хуже: номера разные у дублей одного слова.

Слово `0601_Ketnioq`, три папки (по папке на телефон):

| папка | дубль a | дубль b |
|---|---|---|
| 1 | — | device_1 |
| 2 | device_3 | device_2 |
| 3 | device_1 | device_3 |

**Чем мешает.** Номер = ракурс камеры (1 слева, 2 фронт, 3 справа). Модель усредняет
предсказания трёх ракурсов, на этом она выигрывает 9% точности. Перепутанный ракурс
портит обучение.

**Что сделать.** Привязать номер к серийнику телефона, а не к порядку подключения.
Писать серийник в лог при старте сессии.

---

## 2. Лог говорит «сохранено», а файла нет

**Что происходит.** В логе `STOP_SAVE status: ok`, на диске файла нет. 14.08 — 14 клипов.

**Чем мешает.** Оператор не знает о потере и не переснимает. Дырка находится через
несколько дней.

**Что сделать.** Отдавать `ok` только после того, как файл реально записан и закрыт.

---

## 3. Подтверждение съезжает на одну запись → две записи в одном файле

**Что происходит.** Камера не закрывает файл по «стоп» и пишет дальше, сквозь паузу
и следующую запись. Итог: файл с двумя жестами, а следующего файла нет вообще.

Пример 12.08, камера 1:

```
16:34:41  стоп записи 2502  → камера подтвердила файл ПРЕДЫДУЩЕЙ записи 2501
16:34:53  стоп записи 2503  → камера подтвердила файл 2502, длиной 11.4 с вместо 0.8
                              файла записи 2503 нет
```

**Чем мешает.** Файл на месте, имя правильное, размер нормальный — снаружи не отличить.
Такие склейки попадают в датасет молча.

**Что сделать.** Если файл не закрылся к своему «стоп» — отдавать `error`, а не `ok`.

## 4. Нельзя добавить нового сайнера

13.08 новый человек (Азиза) снимался под чужим номером, потому что завести его было
нельзя. 200 записей пришлось переназначать вручную.

**Что сделать.** Кнопку «добавить сайнера». И поправить имя: сейчас приложение пишет
`signer_11_Нигора_под_вопросом` — служебная пометка попала в имя папки.

## 5. Логи

Сейчас логи присылают по запросу на следующий день, разбор съёмки из-за этого стоит сутки.

**Что сделать.** Складывать в отдельную папку, файл создавать сразу после сессии.

## 6. Мелочи интерфейса

- пропал прицел (рамка кадрирования);
- кадр разворачивается горизонтально при нажатии «старт».

## Как проверить, что починили

1. Снять 20 записей тремя телефонами.
2. В каждой папке все файлы должны быть с номером своего устройства — без исключений.
3. Число файлов на диске = числу `STOP_SAVE ok` в логе.
4. Длительность каждого файла ≈ разнице между `START` и `STOP` в логе.

Если все четыре условия выполняются — пункты 1, 2 и 3 закрыты.
